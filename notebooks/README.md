# Notebooks

* `inspection/` – data quality, coverage and sanity checks on the curated store. Run after every backfill.
* `research/` – alpha research. Copy `00_research_template.ipynb` to start a new study.

Start JupyterLab with `uv run jupyter lab` from the repo root. Outputs are stripped on commit by
`nbstripout` (`uv run nbstripout --install`).
